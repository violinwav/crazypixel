## Design Context

### Users
Small friend groups playing a Brändi Dog-style marble race card game, either hotseat on
one shared device (local) or remote over a room code (online). Sessions are casual,
social, played on phones as often as desktop — the pregame menu is the first thing a
new participant sees, often typed one-handed while a friend reads them a code out loud.

### Brand Personality
Retro-arcade terminal. Blocky, monochrome UI chrome (color is reserved for cards and
player marbles, never decoration) with a console/CRT voice — like booting into a
cabinet, not a modern app. Confident and a little irreverent, not polished-corporate.

### Aesthetic Direction
- Dark theme, `#000` stage, already established (`styles/theme.css`) — keep it.
- Single font family throughout: **Departure Mono** (retro-terminal monospace),
  replacing the current Press Start 2P / Pixelify Sans pairing. One family carries
  title, body, and button text — hierarchy comes from size/weight/spacing, not a second
  face.
- UI chrome stays monochrome (ink/panel/raised grays); player color and card suit color
  are the only chromatic accents, same rule as today.
- Anti-reference: generic SaaS card-grid dashboards, glassmorphism, gradient text,
  rounded-corner icon-above-heading blocks — none of that fits a terminal/arcade voice.

### Design Principles
1. Compact, mobile-first: every control stretches/wraps to fit a narrow viewport with no
   clipping; nothing assumes desktop width.
2. One console font, hierarchy via size/weight, not font-pairing.
3. Chrome monochrome, accent color reserved for player/card identity only.
4. Terminal voice in copy and motion: quick, blocky, no soft easing/bounce.
5. Multiplayer never asks for a player count up front — the lobby adapts to who's
   actually in the room; only local/singleplayer picks a fixed count.
